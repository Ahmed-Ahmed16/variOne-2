## Key invariants — DO NOT regress
- **SubGHz saves → LittleFS**, by design ([rf_scan.cpp `RCSwitch_SaveSignal`](src/modules/rf/rf_scan.cpp)). SD shares the SPI bus with CC1101; saving a `.sub` right after RX collides with the radio mid-transaction (`sdCommand cmd 0x00`). IR/NFC/WiFi stay on `getFsStorage()`→SD. Replay picker already offered LittleFS ([rf_send.cpp:28](src/modules/rf/rf_send.cpp#L28)). Revert to `getFsStorage(fs)` only once SD shares the CC1101 bus under a mutex.
- **NRF must route to `CC_NRF_SPI` (HSPI), never the TFT instance.** The TFT-branch guard in [nrf_common.cpp:49](src/modules/NRF24/nrf_common.cpp#L49) is load-bearing — DO NOT revert. TFT bus has MISO=-1 → `RF24::begin()` returns 0.
- **NRF and CC1101 are the SAME SPI host (HSPI), same pins 11/12/13, differing only by CS** (NRF=15, CC=10). That is a normal shared bus, not a host conflict. CC1101 set-up pattern is [rf_utils.cpp:239](src/modules/rf/rf_utils.cpp#L239) (`end(); delay; begin(); initCC1101once`).
- **CC1101↔TFT coexistence trick = a deliberate `tft.drawPixel(0,0,0)` poke** after each radio bus use, to re-grab GPIO 11/12 onto SPI2 ([rf_waterfall.cpp:129](src/modules/rf/rf_waterfall.cpp#L129), [:176](src/modules/rf/rf_waterfall.cpp#L176)). The NRF draw path has no equivalent.
